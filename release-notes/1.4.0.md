Personal fork of [Lorenzo-Coslado/macos-faceid](https://github.com/Lorenzo-Coslado/macos-faceid), based on upstream v1.3.0.

## What changed

- **No automatic unlock.** The Mac no longer unlocks by itself when you lock the screen or the screen saver starts. It stays locked until you ask for an unlock.
- **Unlock on request.** On the lock screen, press one trigger key (Backspace by default) and Mugshot checks your face, then types your saved password. You get one chance per lock: any other key cancels it until the next lock. The chance also expires after a timeout.
- **Settings → Lock screen:** choose the trigger key (Backspace, Forward Delete, Escape, Tab, `, Home, End, Page Up/Down, F13–F16) and the unlock window with a slider from 1 minute to 2 hours (default 5 minutes). Keep your key private.
- **Keyboard read at the HID level.** The lock screen password field hides keystrokes from normal listeners, so Mugshot uses Input Monitoring to see the trigger key. It works after Ctrl+Cmd+Q, Touch ID and screen saver locks.
- **More reliable password typing** on the lock screen (the field is woken up first, then the password is typed one character at a time).
- **Optional liveness check** (head swing) for the lock screen, off by default. Enable with `FACEID_LOCK_LIVENESS=1`.
- **Automatic update checks are off.** Otherwise Sparkle replaces this build with the official release and resets your permissions.
- **Build tooling:** `scripts/dev-install.sh` builds, installs or releases a local build. Dev builds now find the project when run outside the bundle.

## Install

This package is signed with a self-signed local certificate and is **not notarized**. Remove the download quarantine first:

```
xattr -d com.apple.quarantine Mugshot-1.4.0.pkg
sudo installer -pkg Mugshot-1.4.0.pkg -target /
```

Then grant Accessibility, Camera and Input Monitoring to Mugshot once.
